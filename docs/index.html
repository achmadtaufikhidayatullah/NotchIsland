Jalan pintas lewat Terminal

Sebagai ganti langkah 3–5: setelah app ada di folder Applications, jalankan perintah ini di Terminal, lalu buka NotchIsland seperti biasa.

xattr -dr com.apple.quarantine /Applications/NotchIsland.app

Ada masalah?

“NotchIsland is damaged and can’t be opened”

Ini peringatan karantina macOS, bukan file rusak. Jalankan perintah Terminal di atas, lalu buka app lagi.

Tombol “Open Anyway” tidak muncul

Tombol itu baru muncul setelah kamu mencoba membuka app sekali (langkah 3) dan hanya bertahan sekitar satu jam. Buka NotchIsland sekali lagi, klik Done, lalu kembali ke Privasi & Keamanan.

App terbuka tapi tidak terlihat apa-apa

Wajar: tidak ada jendela biasa. Cari ikon kapsul di menu bar. Di Mac tanpa notch, island hanya muncul saat ada aktivitas — arahkan kursor ke tengah atas layar atau pilih Sisi kanan layar di Pengaturan › Tampilan. Bila menu bar penuh, ikon kapsul bisa tersembunyi di balik notch; tutup beberapa ikon lain.

Cara memperbarui ke versi baru

Ikon kapsul › Keluar. Unduh DMG terbaru, seret ke Applications, pilih Ganti (Replace), lalu buka. Peringatan langkah 3–5 bisa muncul sekali lagi untuk versi baru. Cek versi terbaru: Pengaturan › Umum › Cek pembaruan.

Status Claude tidak muncul

Pastikan Pengaturan › Integrasi › Claude Code sudah Hubungkan, lalu mulai prompt baru di Claude Code. Persen limit resmi muncul setelah aplikasi Claude Desktop dibuka sekali.

Cara mencopot

Pengaturan › Integrasi › Lepas untuk Claude Code & Terminal, lalu ikon kapsul › Keluar, dan hapus NotchIsland dari folder Applications.

Lebih suka build sendiri dari source? Ikuti panduan di GitHub.

Privasi

Semuanya tetap di Mac-mu.

NotchIsland tidak mengirim data ke server mana pun dan tidak menyimpan prompt atau isi percakapan. Source-nya terbuka, jadi siapa pun bisa memeriksanya.

Apa saja yang dibaca?

Status sesi dari hook Claude Code, persen limit dari cache Claude Desktop, status & kuota Antigravity lokal, info "Now Playing" sistem, dan command terminal yang selesai. Daftar lengkapnya ada di README.

Apakah mengubah konfigurasi saya?

Hanya bila kamu mengaktifkan Integrasi: satu entri hook di ~/.claude/settings.json dan satu baris di ~/.zshrc, selalu dengan konfirmasi dan backup. Bisa dilepas kapan saja dari menu.

Apakah ini aplikasi resmi Anthropic / Google?

Bukan. NotchIsland adalah proyek independen dan tidak berafiliasi dengan Anthropic, Google, maupun Apple.

Mac saya tidak punya notch, bisa?

Bisa. Di Mac tanpa notch (mis. MacBook Air M1, Mac Intel, monitor eksternal), island tidak terlihat saat diam, jadi tidak menutupi tab browser atau judul jendela. Island muncul saat ada aktivitas, atau saat kursor berhenti sebentar di tengah atas layar, dan otomatis disembunyikan saat app full-screen.

Kenapa ada peringatan saat pertama dibuka?

Karena app belum ditandatangani sertifikat Apple Developer. Cukup klik "Tetap Buka" di Pengaturan Sistem › Privasi & Keamanan sekali saja.
